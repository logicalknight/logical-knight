Company

A small software company for real work.

Logical Knight builds practical software for small and growing businesses. We look for real problems and build focused tools around them.

Why we exist

A lot of important work still runs on spreadsheets, e-mail and memory. Large software is often too broad, too expensive or too hard to change for one specific job. So people end up working around their tools instead of with them.

We think there is room for software that does one job well, explains itself, and is honest about what it does and does not do.

Problems we care about

  • Work that is done by hand, again and again.
  • Information spread over files, inboxes and binders.
  • Records that must be right, and must be easy to show.
  • Data that nobody fully trusts yet.

What founder-led means here

Logical Knight is run by its founder. The person who decides what gets built also talks to the people who use it. There is no sales team in between, and decisions are short.

It also means we are small. We take on what we can do well, and we say so when we cannot.

What good software should do

  • Useful before impressive

    A tool should save time or prevent mistakes from the first week. Features that only look good in a demo can wait.

  • Clear over complicated

    Plain words, clear screens, no surprises. If something needs a manual to understand, we have more work to do.

  • Human control where it matters

    Software can check, sort and point things out. Important decisions stay with people, and changes stay visible.

  • Build, test, learn

    Early versions go to real users. We listen, and the product grows from real use, not from guesses.

How we build

Products start small, go to real users early, and get better from what we learn.

  1. 01

    Listen

    We start with the people who have the problem, and how the work is done today.

  2. 02

    Build

    We build the smallest version that really helps. Nothing extra.

  3. 03

    Test

    Real users try it with real work. That is where we learn the most.

  4. 04

    Improve

    We fix what is confusing, keep what works, and grow from there.

Pilots and early access

IPPC Ledger runs as a pilot. Data Workbench is in Free Early Access. Both mean the same thing for us: real businesses use the software with their own work, and we improve it from what they tell us. Early access is not a permanent free plan.
