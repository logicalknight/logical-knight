Data Workbench Free Early Access

Turn CSV and Excel files into checked, understandable data.

Data Workbench helps small teams clean up messy spreadsheets without losing track of what changed. Your original file stays as it was. The changes that matter wait for you to approve them.

Free for now, while we learn from real use. We review every request personally.

Spreadsheets you cannot fully trust.

Files arrive from suppliers, shops and other systems. Prices use commas, product codes lose their leading zeros, and columns are empty or mean different things.

Fixing it by hand takes time. And afterwards, nobody can say exactly what was changed, or why.

How it works.

From a raw file to an output you approved.

  1. 01

    Upload

    A CSV or Excel file. The original is stored exactly as received.

  2. 02

    Check quality

    See types, gaps, duplicates and suspicious values, column by column.

  3. 03

    Prepare

    Choose how each column is read. Nothing is guessed.

  4. 04

    Review changes

    See every value before and after, and decide the open questions.

  5. 05

    Approve

    Approve the exact output, then download it.

  6. 06

    Analyse

    Run documented analysis on approved data, with methods and limits stated.

  7. 07

    Dashboard

    Build private dashboards for your organisation.

Important changes wait for you.

The review screen shows the original value, the prepared value and why it changed.

  • Your original file is never changed.
  • Every change is recorded.
  • Anything the rules cannot read waits for your decision instead of being guessed.
  • Nothing is approved automatically.
