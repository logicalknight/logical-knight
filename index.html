We build for real work.

Businesses deal with problems that big software does not always solve well. They are too specific for a large product, but too important to ignore.

That is where we come in. We build focused tools that solve one problem properly.

The kind of work we mean

  • Records that have to be right, and easy to show when someone asks.
  • Information spread across binders, inboxes and spreadsheets.
  • Files that need checking before anyone can trust them.

What we are building.

Two products so far. Each one started with a single, real problem.

Pilot phaseFor wood-packaging businesses

IPPC Ledger

The problem
Delivery notes, supplier authorisations and treatment records sit in binders, inboxes and spreadsheets, so gaps show up late.
What it does
IPPC Ledger keeps timber deliveries and their ISPM 15 evidence together, shows what is missing and why, and exports the records for a job or a period.

Learn more: IPPC Ledger

Free Early AccessFor teams that work with CSV and Excel files

Data Workbench

The problem
Business data arrives as messy CSV and Excel files, and after fixing it by hand nobody can say exactly what changed.
What it does
Data Workbench checks and prepares those files, shows every change before and after, and only moves on with data a person has approved.

Learn more: Data Workbench

How we build.

Products start small, go to real users early, and get better from what we learn.

  1. 01

    Listen

    We start with the people who have the problem, and how the work is done today.

  2. 02

    Build

    We build the smallest version that really helps. Nothing extra.

  3. 03

    Test

    Real users try it with real work. That is where we learn the most.

  4. 04

    Improve

    We fix what is confusing, keep what works, and grow from there.
